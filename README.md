## como rodar
primeiro chequem se o PC de vcs tem python e o pip:
```
python --version
pip --version
```
depois é só instalar esses pacotes:

no Windows
```
pip install numpy opencv-python
```

no Mac
```
pip3 install numpy opencv-python
```

depois só rodar um 
```
python *nome do exercicio*
```
